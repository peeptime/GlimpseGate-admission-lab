## v2.4.0 — Gate GUI v3

**中文摘要**：界面重做（准入 / 资料库 / 系统）。修复两个底层问题：界面绕过 SDK 自己跑正则；本地服务可被任意网页跨站调用。节点网络 + 分形路由图标 + 噪声场的动效设计，旧界面保留在 `/classic/`。

### Fixed
- **The GUI bypassed the SDK.** `/api/lite-audit` and `lite.html` ran their own regex auditors, so GUI routes could disagree with the SDK. All GUI audits now go through SDK functions.
- **No request guard.** Any page open in the same browser could POST `text/plain` to `/api/run` or `/api/artifact`. Now: loopback Host only, same-origin + JSON for state changes, CSP on HTML.
- `goal-validator.mjs` ran its CLI on import and could `process.exit(1)` the server. Static containment check was not separator-aware.

### Added
- **Dashboard v3**: Gate (paste → decision → admit-as choice → admission contract), Library, System. The SDK decision tree as a node network; route glyphs as levels of subdivision; noise-driven quadtree and curl-noise field. zh/en, reduced-motion aware, offline, no build step.
- `/api/v1/admission/{audit,contract,meta}`; route table; `createDashboardServer()`; API contract + security tests in `npm test`.
