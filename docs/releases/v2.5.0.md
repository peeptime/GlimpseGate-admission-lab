- Translation marking in the GUI; one-click original/translation toggle; language switch re-localizes the current result.
- Stable feedback codes for agents (`fix.*`, `gap.*`, `option.*`, …).
- Coverage test: statically scans the SDK and fails on any untranslated feedback string (76 literals + 6 templates).
- Found and handled: the SDK's human-review checklist is Chinese-only (reverse zh→en catalog).
